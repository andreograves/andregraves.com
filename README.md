# andregraves.com

André O. Graves photography portfolio. Hosted on GitHub Pages.

- `index.html` is the whole site, styled to match the live Adobe Portfolio site: splash (`#home`), cover grid (`#work`), 8 galleries (`#001-people` … `#008-animals`), About (`#about-me`) and a lightbox.
- Covers are `img/cover-<category>.jpg`; the About background is `img/about-bg.jpg`.
- Photos are in `img/`, named by category. To add photos, put them in `img/` and list them in the `PHOTOS` data near the bottom of `index.html`.
